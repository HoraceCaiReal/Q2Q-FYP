## 1. 概述

Q2Q（Qualitative-to-Quantitative）是一种面向边缘设备的神经符号控制架构。其核心思想：

> **将控制分解为“定性策略选择”和“定量参数生成”。神经网络负责选择策略（case）并输出参数（params），符号后端（OSQP/A*）负责求解最优动作。两者通过凸组合混合，形成闭环反射弧。**

Q2Q 由四部分组成（2026-10-19 晚更正）：

| 组件 | 职责 | 可微性 |
|---|---|---|
| Q2Q-VLM（**含 Km-Transformer**） | 策略选择 + 参数预测 | 可微 |
| Harness（Q2Q-VLM 外壳） | 状态 → token → 调模型 → 取输出 | 不可微 |
| Orchestration（总调度） | 调度、路由、完成判定、恢复、记账 | 不可微 |
| 符号后端 | OSQP / A* 求解 | 不可微 |

**核心叙事**：不是所有智能都需要云端大模型。边缘反射弧 + 云端规划 = 完整具身智能。

## 3. Km-Transformer 详细设计

### 3.1 输入定义

**内态（传感态）**：直接测量的物理量，可信度高。

- 关节角、关节速度、末端位姿、夹爪状态、力/力矩、图像

**外态（非传感态）**：推断或给定的上下文，可信度低。

- 子目标、prompt、约束、视觉 token、进度、历史

**类型嵌入**：区分 CLS、PARAM、内态、外态。

### 3.2 序列结构

```
位置:   0     1      2~17        18~33
       ┌───┬─────┬────────────┬────────────┐
       │CLS│PARAM│ 内态 token  │ 外态 token │
       │   │     │   ×16      │   ×T_n     │
       └───┴─────┴────────────┴────────────┘
         ↑     ↑        ↑            ↑
      策略输出 参数输出  α极化位置    β极化位置
```

每个 token 加类型嵌入。总长度 = 1 + 1 + 16 + T_n。

### 3.3 两次前向

构建两个条件序列：

- **x1（反射条件）**：`[CLS][PARAM][内态][0]` — 外态置零
- **x2（任务条件）**：`[CLS][PARAM][内态][外态]` — 正常

### 3.4 β 门控：模态极化

作用于 x2 内部，极化内态和外态：

```python
scores = Linear([内态, 外态])          # (B, T_n, 2)
β = softmax(scores, dim=-1)[..., 0:1]  # (B, T_n, 1)
x2[外态] = β * x2[外态]
```

- β 大：压制外态，强调内态
- β 小：强调外态
- **不涉及相加，原路拼接**

### 3.5 Cross-Attention：互相关

x1 和 x2 互相查询：

```python
O1, O2 = CrossAttention(LN(x1), LN(x2))
```

- 提取两个条件之间的互相关信息
- 对应信号处理中的互相关运算

### 3.6 α 门控：策略极化

从互相关输出计算 α：

```python
scores = Linear([pool(O1), pool(O2)])   # (B, 2)
α = softmax(scores, dim=-1)[..., 0:1]   # (B, 1)
```

- α 大：偏向反射（安全优先）
- α 小：偏向任务（执行优先）

### 3.7 凸组合混合

```python
mixed = α * x1 + (1 - α) * x2
```

**数学保证**：凸组合保证 `mixed` 始终在 x1 和 x2 的凸包内，不会失真、不会爆炸。

### 3.8 FFN + 残差

```python
mixed = mixed + FFN(LN(mixed))
```

### 3.9 输出层

LayerNorm + 可学习池化 + 降维投影：

```python
case_repr = case_proj(CLS位置)           # 策略表示
param_repr = param_proj(attention_pool)  # 参数表示
```

分别送入 case_head 和 param_heads。

### 3.10 完整 Q2QBlock

```python
class Q2QBlock(nn.Module):
    def __init__(self, d_model):
        self.ln1 = LayerNorm(d_model)
        self.cross_attn = CrossAttention()
        self.ln2 = LayerNorm(d_model)
        self.ff = FeedForward()
        self.beta_proj = Linear(d_model*2, 2)
        self.alpha_proj = Linear(d_model*2, 2)

    def forward(self, x1, x2):
        # β 极化
        x2_int = x2[:, 2:18, :]
        x2_ext = x2[:, 18:, :]
        z = cat([x2_int, x2_ext], dim=-1)
        beta = softmax(self.beta_proj(z), dim=-1)[..., 0:1]
        x2[:, 18:, :] = beta * x2_ext

        # 互相关
        O1, O2 = self.cross_attn(self.ln1(x1), self.ln1(x2))

        # α 极化
        z = cat([O1.mean(1), O2.mean(1)], dim=-1)
        alpha = softmax(self.alpha_proj(z), dim=-1)[:, 0:1]

        # 凸组合
        mixed = alpha * x1 + (1 - alpha) * x2

        # FFN
        mixed = mixed + self.ff(self.ln2(mixed))
        return mixed
```

### 3.11 迭代反馈（后训练/执行阶段可选）

将上一轮的 CLS 和 PARAM 替换回输入，迭代 N 次：

```
第1轮: [CLS₀, PARAM₀, 内态, 外态] → [CLS₁, PARAM₁]
第2轮: [CLS₁, PARAM₁, 内态, 外态] → [CLS₂, PARAM₂]
...
```

每轮监督，预训练不迭代，执行时按需迭代。

### 3.12 反射模式

外态全为 0 时，模型自动降级为纯反射弧：

```
[CLS][PARAM][内态][0] → 输出反射策略（趋利避害）
```

无需额外 fallback 模块，架构自带优雅降级。

## 4. Orchestration 编排层（总调度）

> 本节标题原为 “Q2QHarness 编排层”，按 2026-10-19 晚的概念更正改为 orchestration。
> **harness 不是调度者**：它只是 Q2Q-VLM 的外壳（预处理成 token → 调模型 → 取输出）；
> 下表里「模型调用」那一行属于 harness 的职责，其余属于 orchestration。

### 4.1 组件

| 组件 | 职责 |
|---|---|
| 子目标解析器 | LLM 输出 → 结构化子目标 |
| 状态管理 | WorldState，历史，进度 |
| 数据采集 | ROS2 订阅，组装内态/外态 |
| 模型调用 | Km-Transformer 推理 |
| 策略路由 | case → 求解器 |
| 求解器封装 | OSQP / A* / Hybrid A* |
| 执行监控 | ROS2 发布，状态监控 |
| 错误恢复 | 重试 / 换 case / 重规划 |
| 日志记录 | 全链路可追溯 |
| 在线纠错 | 人工/LLM分析 + LoRA微调 |
| 可视化 | α/β 热力图，case分布 |

### 4.2 主循环

```python
def run(self, task):
    subgoals = self.planner.plan(task, self.state)
    for subgoal in subgoals:
        self.state.current_subgoal = subgoal
        success = self.execute_subgoal(subgoal)
        if not success:
            action = self.recovery.handle_failure(subgoal, self.state)
            if action == "retry":
                success = self.execute_subgoal(subgoal)
            elif action[0] == "change_case":
                self.state.forced_case = action[1]
                success = self.execute_subgoal(subgoal)
            else:
                subgoals = self.planner.replan(task, self.state)
                break
    return self.state.task_progress >= 1.0
```

## 5. 符号后端

### 5.1 OSQP（机械臂操作）

```python
def solve_osqp(case_params, state, subgoal):
    P, q, A, l, u = build_qp(case_params, state, subgoal)
    prob = osqp.OSQP()
    prob.setup(P, q, A, l, u)
    result = prob.solve()
    return result.x
```

保证：最优性 + 约束满足。

### 5.2 A* / Hybrid A*（移动导航）

```python
def solve_astar(case_params, state, subgoal):
    grid = build_grid(state.map, case_params["grid_resolution"])
    path = astar(grid, state.position, subgoal.target,
                 heuristic=case_params["heuristic"])
    return path
```

### 5.3 solver-agnostic

Harness 根据 case 参数中的 `solver` 字段路由到对应求解器。

## 6. 上层规划接口

LLM/WM 输出结构化子目标：

@dataclass
class Subgoal:

- case → 初始化 CLS token
- prompt → 文本 token
- constraints → 数值 token

三者加上视觉 token 组成外态序列。

## 7. 训练方法

### 7.1 预训练

**数据采集**：随机环境 + 兜底触发 + 自动标注。

- 随机环境：障碍物、噪声、外力、任务变化
- 兜底触发：碰撞风险、传感器故障、执行卡住、case置信度低
- 自动标注：从轨迹反推 case 和 params

**四类样本**：正常、边界、恢复、失败。

**双模式训练**：随机清空外态（10%），学会反射模式。

**损失函数**：

```python
loss_case = CrossEntropy(case_logits, case_label)
case_correct = (case_logits.argmax(-1) == case_label).float()
loss_param = (MSE(param_pred, param_label) * case_correct).mean()
loss = loss_case + λ * loss_param
```

### 7.2 后训练

**第一阶段（RL）**：用 reward 更新策略（RLHF / DPO）。

**第二阶段（在线纠错）**：兜底触发 → 记录 → 分析 → 注入正确 token → LoRA 微调。

## 8. 可解释性与理论分析

### 8.1 α 和 β 可视化

- β：层 × 内态维度，反映传感器信任度
- α：层 × 时间，反映安全 vs 任务偏向
- α-β 相关性分析：验证正交性（|r| < 0.3, MI ≈ 0）

### 8.2 凸组合的数学保证

`mixed = α·x1 + (1-α)·x2` 是凸组合，保证：

- 有界性：输出在 [x1, x2] 内
- 数值稳定性：无梯度爆炸
- 安全性：token 不偏离预训练范围

### 8.3 信号处理视角

- Self-Attention = 自相关
- Cross-Attention = 互相关
- α 和 β = 自适应滤波系数（策略极化 / 模态极化）
- 整体 = 三段式信号处理流水线：预处理（β极化）→ 核心处理（互相关）→ 后处理（α极化+混合）
