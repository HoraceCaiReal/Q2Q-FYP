# 自研 Harness 与开源执行后端的分工决策

日期：2026-10-15。状态：用户已同意。依据：当日对话及平台调研；本文为整理摘要，不是逐字聊天记录。

## 目标与约束

机械电子大四 FYP，题目 Autonomous Robotic Bin Picking for Warehouse Order Fulfillment，导师 Marcelo H Ang Jr。ROS2 通信为硬要求，允许仿真。10 月 26 日前需基础 demo，并争取初步完成 Harness 各核心组件与调度；每天几乎可投入整个下午。个人能力提升与工程可评测性优先。

## 比较与决定

| 路线 | 主要收益 | 主要代价 | 结论 |
|---|---|---|---|
| 在 darshmenon 完整平台内改造 | 复用已有抓放、采集与调度 | 需理解和调整他人上层架构；依赖复现仍有风险 | 不作为整体开发底座 |
| 从模型、仿真到 Harness 全部自建 | 学习覆盖广 | 基础设施集成占用近期时间 | 不采用 |
| 独立自研 Harness，接入开源执行后端 | 自己掌握核心接口、状态、调度、监控与评测，底层可替换 | 仍需适配与仿真验收 | 采用 |

个人主要实现：任务状态机、调度器、state monitor、有限恢复、事件与数据记录、评测。助手协助环境、接口解读、代码审查和验证设计。旧日志中的分工禁令不自动继承。

## 已选平台与组件

- Ubuntu 22.04 / ROS2 Humble / Gazebo Fortress / Clearpath Simulator。
- Husky A200 + Kinova Gen3 Lite + Kinova 2F Lite 夹爪；TIAGo 作为备选。
- Nav2；规划控制初始候选 NavFn + DWB，先核对并复现平台配置。
- 固定地图 + AMCL；MoveIt2 + OMPL；配套 ros2_control 控制器。
- tf2、关节状态、里程计、仿真时钟；rosbag2 + JSONL 事件记录 + CSV 指标；RViz2。
- 自建轻量仓库 SDF，参考 Clearpath warehouse 结构；不将已归档 AWS RoboMaker 项目作为维护中的底座。
- 独立 Python/rclpy Harness；Nav2 自己的导航行为树保留在导航子任务内部。

本决策未固定全部软件包版本、插件参数、场景尺寸或控制频率；这些需要实测。未进行平台下载或安装。

## 近期 Harness 的完成含义

每个组件都具备最小可运行行为，能共同完成闭环：结构化订单解析、状态与时间戳、规则 case/params 策略接口、异步执行适配、反馈/取消/超时、监控、有限重试和终止、episode 采集、结果统计。仅有目录或空类不算完成。

先通过可控测试执行端验证调度与故障，再接物理仿真。测试执行端不证明物理抓取能力。模型、LLM/WM、在线 LoRA、RL、自研 QP 控制不是近期前置要求。

建议验证窗口为最多两个下午；若候选平台不能稳定复现，缩小依赖与场景或转备选，不让底层问题阻塞 Harness 独立开发。此时间预算是工程安排，不是交付保证。

## 后续评价依据

正常任务、执行失败、状态过期、超时与取消都有可观察结果；拒绝重复派发；恢复有上限；实际动作与观测分开记录。场景版本、配置、策略来源、随机种子、episode ID 可追溯。

模型结构以作者根目录 v2.0 为当前设计来源；设计中的理论及安全主张不作为已经验证的实验结果。
